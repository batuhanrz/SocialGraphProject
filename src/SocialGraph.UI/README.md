# SocialGraph.UI

React ve TypeScript tabanli kullanici arayuzu.

## Sorumluluk
- Graf gorselletirme (Vis-network, 2D node-link diyagrami)
- Arama arayuzu (Trie autocomplete entegrasyonu)
- Sorgu paneli (BFS, DFS, shortest path, zincir sorgular)
- Yan panel etkilesimi (dugum detaylari, komsuluk listesi)

## Teknoloji
- React + TypeScript
- Vis-network
- Vite
