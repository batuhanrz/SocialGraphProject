# SocialGraph.API

Property Graph verilerinin ve RAM tabanli veri yapilarinin tutuldugu ana is mantigi servisi.

## Sorumluluk
- Node/Edge modelleri ve Property Graph yonetimi
- Custom Hash Table, Trie ve Queue veri yapilari
- REST API endpointleri (Controller -> Service -> Data)
- Singleton yasam dongusu ile in-memory veri yonetimi

## Teknoloji
- ASP.NET Core Web API
- C#
